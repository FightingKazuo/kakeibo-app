# 🏠 家計簿アプリ — セットアップガイド

## 必要なもの

- **Node.js 18以上**（インストール済みか確認: `node -v`）
- **npm**（Node.jsに付属）

Node.jsが入っていない場合は https://nodejs.org からLTS版をインストールしてください。

---

## 起動手順（5ステップ）

### ① フォルダに移動

```bash
cd kakeibo-app
```

### ② パッケージをインストール（初回のみ）

```bash
npm install
```

※ `node_modules/` フォルダが作られます。数分かかります。

### ③ 開発サーバーを起動

```bash
npm run dev
```

### ④ ブラウザで開く

ターミナルに表示された URL（通常 `http://localhost:5173`）をブラウザで開く。

### ⑤ スマホで確認する場合

同じWi-Fiに繋いだスマホのブラウザで、
ターミナルに表示された `Network: http://192.168.x.x:5173` を開く。

---

## 本番ビルド（配布・公開するとき）

```bash
npm run build
```

`dist/` フォルダが生成されます。このフォルダをサーバーにアップロードすれば公開できます。

### Netlify で無料公開する場合

1. https://netlify.com にアカウント作成
2. `npm run build` を実行
3. `dist/` フォルダをNetlifyのダッシュボードにドラッグ＆ドロップ
4. URLが発行される（例: `https://kakeibo-abc123.netlify.app`）

## よくあるエラー

### `node: command not found`
→ Node.jsをインストールしてください: https://nodejs.org

### `npm install` でエラー
→ Node.jsのバージョンを確認: `node -v`（18以上が必要）

### ポート5173が使えない
→ 別のポートで起動: `npm run dev -- --port 3000`
